## 05 作品介绍（不少于 30 字）

> 写代码的人每天都在提交，但 commit message 大多随手写成 update、fix bug，三个月后回头找改动只能一条条点开 diff。gcm 读取项目的 git diff，让 AI 按 Conventional Commits（Angular 规范）生成「type(scope): 描述 + 为什么改」的提交信息，一次给 1 条推荐加 2 条备选，确认后一键提交。
>
> 目标用户是个人开发者和需要统一提交规范的团队。体验方式：打开作品链接，可以直接粘贴一段 git diff 在线出稿，或粘贴自己的 commit message 做规范体检（实时打分并逐条指出问题）；完整能力提供三种入口——MCP 接入 WorkBuddy（零 API Key、零成本）、双击 start.bat 的本地网页版、以及命令行 gcm.js。开源地址：https://github.com/cifeng/gcm
